**CampusConnect**

The goal is to create a website that is not just a static college website, but a **functional digital college ecosystem** that students, professors, HODs, and administrators can actually use in their daily college activities.

The application should have a clean, modern, premium UI with excellent usability. It should work smoothly on desktop, tablet, and mobile.

## 1. MAIN GOAL

Create one centralized platform where students and faculty can access:

* Academic activities
* College events
* Student CGPA and academic performance
* Attendance
* Timetable
* Assignments
* Notices and announcements
* Exams and results
* Faculty information
* Courses and subjects
* Study resources
* Leave applications
* Complaints and feedback
* Campus services
* Notifications
* Profile and account management

The website should feel like a real product that a college could actually deploy.

# 29. IMPORTANT CALCULATIONS

Implement functional calculations for:

### CGPA

Calculate overall CGPA using credit-weighted academic performance.

### SGPA

Calculate semester GPA from subject grades and credits.

### Attendance

Calculate:

Attendance % = Classes Attended / Total Classes × 100

Also calculate required future attendance based on the college's configurable minimum attendance rule.

These values should update automatically when underlying data changes.

# 36. FINAL REQUIREMENT

The final application should feel like a **real Smart College Operating System**, not just a college information website.

The core idea is:

**“One Platform. Complete College Life.”**

Students should be able to manage their academic life.

Professors should be able to manage teaching-related tasks.

Administrators should be able to manage the college ecosystem.

Prioritize functionality, usability, accessibility, scalability, and a polished user experience.

Make the interface impressive enough for a hackathon/vibe-coding competition while keeping it practical enough for real college use.

Before finishing, test every major navigation item, button, form, filter, calculation, dashboard, role-based workflow, and responsive layout. Fix broken links, console errors, overlapping elements, and non-functional interactions.

Deliver a polished, production-style application with realistic demo data and a clear user experience.
